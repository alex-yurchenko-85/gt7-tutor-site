# Voice clips notice

The files in this folder are speech clips of GT7 Tutor: `big-stop`, `hard-brake`, `speed-115`, `full-throttle` and `ease-off`.
They are copies of the clips in `content/audio/en/clips/` of the main project, <https://github.com/alex-yurchenko-85/gt7-tutor>, converted to AAC (48 kbit/s, mono) for this page.

## Speech model and voice

- Model: Kokoro-82M v1.0, by hexgrad, <https://huggingface.co/hexgrad/Kokoro-82M>.
- Voice: `af_heart` (American English, female), from the voice files of the `kokoro-js` package.
- Licence of the model weights and voices: Apache License 2.0, <https://www.apache.org/licenses/LICENSE-2.0>.
- The Apache License 2.0 sets no restriction on audio that the model generates. The clips can be redistributed.

The speech tool is `kokoro-js`, Apache License 2.0. It runs only in the main project, when its maintainer generates the clips. No code from it is on this site.
